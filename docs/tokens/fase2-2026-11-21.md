## Detalhes
- **MAX_MCP_OUTPUT_TOKENS** (padrão da doc: 25000) → 8000. **BASH_MAX_OUTPUT_LENGTH** (padrão 30000, máximo 150000) → 20000.
- **MAX_THINKING_TOKENS**: já era 8000 no settings global; mantido (teto moderado; a doc exige mínimo de 1024 e, com valor fixo, não usa o raciocínio adaptativo).
- **Tool Search / carregamento lazy de MCP**: variável oficial `ENABLE_TOOL_SEARCH`. O padrão (sem definir) já adia as ferramentas MCP (confirmado: as tools aparecem só por nome até serem carregadas), então **nada foi adicionado**; evita-se inventar configuração. Valores aceitos pela doc: `true`, `auto`, `auto:N`, `false`.
- **Statusline**: script `~/.claude/statusline.py` (Python, lê o JSON do stdin e usa `context_window.used_percentage`, documentado). Mostra `Modelo | ctx NN%` e acrescenta `(compactar)` a partir de 60%. Comando: `<HOME>/.../python.exe -I <HOME>/.claude/statusline.py`. Testado com entrada de exemplo e com `{}` (mostra `ctx --%`).
- **Figma**: `claude plugin disable figma@claude-plugins-official --scope project` (gera `enabledPlugins.figma@...: false` no `.claude/settings.json`). `claude plugin list` no repositório mostra `disabled`. O plugin também estava sem login.
  - Ligar para tarefas de design: `claude plugin enable figma@claude-plugins-official --scope local` (só na sua cópia, sem commit) e reiniciar a sessão.
  - Desligar de novo: `claude plugin disable figma@claude-plugins-official --scope local` ou remover a linha local.

## Medição e limite
O `/context` é interativo e o agente não o roda. Método possível: `claude -p` com `--output-format json` lê `usage` (tokens de entrada/saída e cache) de uma sessão nova. A medição antes/depois é a Fase 5; aqui só vale a configuração.

## Rollback
1. Global: restaurar `settings.global.pre-fase2.json` (backup externo) ou remover `MAX_MCP_OUTPUT_TOKENS`, `BASH_MAX_OUTPUT_LENGTH` e `statusLine`.
2. Figma: `claude plugin enable figma@claude-plugins-official --scope project` ou restaurar `settings.projeto.pre-fase2.json`.
3. Apagar `~/.claude/statusline.py`.
